# Kid Math Lab

Interactive, browser-based probability practice for young learners. Each activity runs entirely in the browser and needs no installation.

## Activities

### Level 1 — Add or Multiply?

Read an English probability word problem and decide whether its probabilities should be added or multiplied. The activity includes 100 randomized questions: 50 addition questions and 50 multiplication questions, with explanations after each answer.

- [Open locally](levels/level-1/index.html)

### Level 2 — Build the Formula

Read a probability word problem, then drag four fraction cards and an operation card into the formula area. It includes 100 randomized questions: 50 addition questions and 50 multiplication questions. Card options include careful distractors for replacement and no-replacement situations.

- [Open locally](levels/level-2/index.html)

## Run locally

Open either `index.html` file in a modern web browser. No build step or network connection is required.
